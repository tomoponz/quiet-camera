# Quiet Camera

ブラウザーで写真と動画を撮影し、履歴から見返せるカメラアプリです。広告やアカウント登録の機能はありません。アプリ独自のシャッター音は再生しませんが、端末・OS・ブラウザーが発する音を止める機能ではなく、無音を保証するものではありません。

この文書は、このリポジトリのmain（表示版 `v2026.10.31.3`）を対象としています。動画への切り替え時にマイクを準備し、手動で選んだOFF設定を維持します。既存の撮影データの保存場所・データベース形式と通常の画面構成は維持しています。開発中の別候補版の機能は含めていません。根拠と確認範囲は[検証記録](docs/verification.md)にまとめています。

## 何ができるか

| 操作 | 内容 |
| --- | --- |
| 写真を撮る | JPEG・PNG・WebP・PDF、セルフタイマー、4:3・1:1・16:9の比率を選べます。写真は表示される保存範囲に合わせて中央を切り抜きます。 |
| 動画を撮る | マイクOFF／ON、解像度・fps・画質・録画時間の上限を設定できます。出力形式はMP4・WebMを優先し、指定できない場合はブラウザーの既定形式を使います。 |
| カメラを調整する | 前後カメラの切り替えや、検出されたカメラの選択ができます。ライト・ズーム・露出・ピントは、カメラとブラウザーが対応している範囲で操作できます。 |
| 履歴から見返す | 写真・動画を開き、撮影順に前後へ移動できます。動画は再生操作で確認できます。 |
| 外へ取り出す | 1件の保存・共有、複数件の選択・ZIP保存、画像の写真を最大20枚まとめたPDF作成ができます。共有先の選択はOSやブラウザーに依存します。 |

端末の縦向き・横向きに合わせて表示を調整でき、全画面表示も利用できます。ただし、どの端末でも同じカメラ機能や画質になるわけではありません。

## 使い始め方

1. [公開アプリ](https://tomoponz.github.io/quiet-camera/)を対応ブラウザーで開きます。初回はインターネット接続が必要です。
2. 「カメラを許可」を押し、ブラウザーのカメラ使用を許可します。
3. 映像が表示されたら、「写真」または「動画」を選びます。
4. 初めて「動画」に切り替えたとき、マイクの使用を求められたら許可します。**手動でOFFにした設定は、次回起動後も維持します。** 録画前に画面の「MIC OFF／ON」を確認してください。

マイクの許可を拒否した場合はMIC OFFとなり、「音声なし」を表示します。アプリ独自の確認ダイアログは重ねません。写真の映像が取得できていた場合は音声なしの映像へ接続し直します。カメラも未起動の状態で拒否した場合は、改めて「カメラを許可」を押してください。詳しくは[データと権限](docs/data-and-permissions.md)を参照してください。

PWAとしてのホーム画面への追加・インストールは、対応するブラウザーのメニューから行えます。インストールは撮影の必須条件ではありません。

## 基本操作

1. **撮影する**：写真はシャッターボタン、動画は録画開始ボタンを押します。動画は同じボタンで停止します。タイマーを設定した場合はカウントダウン後に撮影が始まります。
2. **続けて撮る**：写真の保存や動画の確定が終わると通知が表示され、撮影画面のまま次の撮影に移れます。結果の画面は自動では開きません。
3. **見返す**：履歴ボタン（「履歴」または直近の撮影サムネイル）を押して「撮影履歴」を開き、項目を選びます。詳細画面では左へのスワイプで古い項目、右へのスワイプで新しい項目へ進みます。前後ボタンも利用できます。端では循環せず、次の動画は自動再生しません。
4. **取り出す**：必要な項目で「端末に保存」または「共有」を使います。複数選択は項目の長押しなどで開始します。**履歴に入っただけでは、端末の写真アプリへの保存完了を意味しません。**

設定、ズーム・ライト、写真と動画の保存範囲、履歴の選択操作は[使い方](docs/usage.md)にまとめています。

## データと権限

- 撮影結果と録画の一時データは、利用中のブラウザー・サイトの **IndexedDB** に保存します。カメラ選択などの設定と、手動で選んだマイクOFFは **localStorage** に保存します。
- 確認した公開コードには、撮影した写真・動画・音声を運営者へ自動アップロードする処理は見つかりませんでした。ただし、アプリ本体や更新ファイルを読み込むための通信は行うため、「一切通信しない」わけではありません。
- 「共有」を使った後の送信や、保存先によるクラウド同期は、選んだアプリ・OS・保存先の扱いに従います。
- 履歴からの削除はアプリ内の記録のみが対象です。すでに保存・共有した別のコピーは消えません。サイトデータの消去やブラウザーの容量整理で履歴が失われる場合があるため、大切なデータは別途保存してください。
- カメラは撮影用に使います。手動OFFなどの場合を除き、動画への切り替え時にマイクをONにして利用許可を求めます。写真モードではマイクを使用しません。確認したコードに位置情報権限を要求する処理はありません。

保存場所・通信・削除の範囲は[データと権限](docs/data-and-permissions.md)、公開サイトの方針は[プライバシーポリシー](https://tomoponz.github.io/quiet-camera/privacy.html)を参照してください。

## 制約・対応環境

- カメラ利用にはHTTPSまたは`localhost`などの安全な接続環境と、ブラウザーのメディアAPIが必要です。ローカルファイルを直接開く方法は利用手順に含めていません。
- ライト、ズーム、ピント、露出、1080p、60fps、動画形式、共有、全画面表示は端末・OS・ブラウザーに依存します。設定値の選択は、実際の出力画質や物理的な合焦を保証するものではありません。
- 録画は選択した上限時間のほか、保存容量などの条件により早く停止する場合があります。中断した録画の復元は条件付きであり、強制終了や容量不足からの完全な復旧を保証しません。
- オフライン起動は、アプリ画面のキャッシュが事前に保存されていることが前提です。初回起動、保存領域の保持、すべての端末での動作を保証するものではありません。
- 現在のmainでは、ソース検証と合成メディアによるPC Chromiumの自動試験が成功しています。2026年8月のGalaxy S25・iPad mini 7・Pixel 8aの記録は**当時の版**のものです。現在版の全操作が各実機で確認済みという意味ではありません。

具体的な条件は[制約と対応環境](docs/limitations.md)、コード・自動試験・実機記録の区別は[検証記録](docs/verification.md)を参照してください。撮影時は相手の同意と、その場所の規則を守ってください。
