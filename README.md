# Quiet Camera

写真と動画をブラウザ内だけで処理する、プライバシー重視のカメラPWAです。撮影データは自動送信されず、広告・解析・アカウント機能もありません。

## 主な機能

### 写真

- 前面／背面カメラ切替
- 0秒・3秒・10秒セルフタイマー
- 4:3・1:1・16:9の比率切替
- JPEG・PNG・WebP・1ページPDF出力
- JPEG／WebP品質選択
- タップフォーカス（対応端末）
- スライダー／ピンチズーム（対応端末）
- ライト（対応端末）
- 3分割グリッド
- 保存・共有・削除

### 動画

- 写真／動画モード切替
- `MediaRecorder`による録画
- MP4またはWebMの自動選択
- マイクOFF／ON（初期値はOFF）
- 自動・720p・1080p
- 自動・30fps・60fps
- 軽量・標準・高画質
- 録画時間と音声状態の表示
- 保存・共有・削除
- 録画中の設定変更防止とページ離脱警告

### PWA

- インストール可能
- オフラインでアプリ画面を起動
- Web Share APIによる共有

## プライバシー設計

- 写真・映像・音声を自動アップロードしない
- マイク権限は動画設定をONにした場合だけ要求
- 位置情報を取得しない
- アクセス解析、広告SDK、ログイン、クラウド保存を使用しない
- 撮影結果は保存・共有・削除するまでブラウザ内に一時保持

## ローカルで確認

カメラ機能はHTTPSまたは`localhost`で動作します。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000`を開きます。

## GitHub Pagesで公開

1. TSUKUTTAで一般公開する場合は、リポジトリの公開範囲を確認する
2. GitHubの **Settings → Pages** を開く
3. **Deploy from a branch** を選ぶ
4. `main`ブランチの`/ (root)`を指定して保存する
5. Android ChromeとiPhone Safariで実機検証する
6. 問題がなければ公開URLをTSUKUTTAへ登録する

公開URLの例:

```text
https://tomoponz.github.io/quiet-camera/
```

## 既知の制約

- タップフォーカス、ズーム、ライト、60fps、1080pは端末とブラウザの対応状況に依存します。
- 動画形式はブラウザが対応するMP4またはWebMから自動選択されます。
- 長時間録画は端末メモリを消費します。現段階では短時間から実機検証してください。
- 写真は動画プレビューのフレームをCanvasへ描画する方式です。標準カメラアプリと画質やHDR処理が異なる場合があります。
- PDFは撮影した1枚をA4ページへ配置する形式です。複数ページPDFは未実装です。
- 端末やOSの仕様により、無音動作を保証できない場合があります。
- iPhoneでは共有シートから「画像を保存」または「ファイルに保存」を選ぶ方法が確実です。

## 実機テスト項目

- Android Chrome／インストール済みPWA
- iPhone Safari／ホーム画面追加後
- 前面／背面カメラ
- マイクOFF／ON
- MP4／WebMの形式選択
- 720p／1080pと30／60fpsのフォールバック
- タップフォーカス、ズーム、ライト
- JPEG／PNG／WebP／PDFの保存と共有
- 録画中のバックグラウンド移行、画面回転、権限拒否

## 利用上の注意

人物や私有地を撮影・録画するときは、相手の同意と撮影場所の規則を守ってください。無断撮影、盗撮、撮影禁止場所での使用など、違法・迷惑な撮影や録画には使用しないでください。
