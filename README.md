# Quiet Camera

写真と動画をブラウザ内だけで処理する、プライバシー重視のカメラPWAです。撮影データは自動送信されず、広告・解析・アカウント機能もありません。

## 主な機能

### カメラ制御

- 前面／背面カメラ切替
- 内蔵カメラ、USBカメラ、仮想カメラを含むカメラ選択
- 選択した`deviceId`の保存と、切断時の自動フォールバック
- カメラの接続・切断を`devicechange`で検出
- 対応カメラだけにズーム、露出補正、手動ピント、ライトを表示
- 露出補正は整数インデックスで管理し、厳密な0EVへリセット可能
- 手動ピントは端末の有効範囲と刻み幅へ丸めて適用
- 設定適用後に`getSettings()`を読み直し、無視された設定を成功扱いしない
- 位置指定AFに対応すると明示されたカメラだけタップ位置を送信
- 位置指定AFがない場合は、単発中央AFまたは手動ピントへ切り替え

### 端末標準カメラ

- 設定画面から「背面で撮影／録画」「前面で撮影／録画」を選択
- Webカメラの許可画面からも端末標準カメラを直接起動可能
- `capture="environment"`または`capture="user"`を使い、対応ブラウザへ前面／背面の希望を通知
- 標準カメラ画面で利用できるタップフォーカス、HDR、夜景処理などを使用可能
- 撮影した写真・動画だけをQuiet Cameraへ戻し、既存の履歴、共有、削除、PDF機能で扱う
- 標準カメラを開く前にWebカメラを停止し、戻った後またはキャンセル後に自動再開
- JPEG、PNG、WebP、HEIC、HEIF、AVIFなどをブラウザがデコードできる場合は履歴用JPEGプレビューを生成
- MP4、MOV、WebMなどは解像度と再生時間を取得して履歴へ追加
- PCなど`capture`がカメラ起動として扱われない環境では、通常のファイル選択として動作

### 写真

- 0秒・3秒・10秒セルフタイマー
- 4:3・1:1・16:9の表示比率切替
- JPEG・PNG・WebP・PDF出力
- 複数写真をまとめた複数ページPDF
- 高解像度撮影がプレビューと一致する場合は`ImageCapture.takePhoto()`を使用
- 高解像度画像とプレビューの比率が異なる場合は、画面表示と一致するプレビューフレームへフォールバック
- スマホの縦長プレビューを含め、画面で見えている比率に合わせて保存
- 自撮りの鏡像保存切替
- 撮影後確認の「毎回・2秒・なし」

### 動画

- MP4またはWebMの自動選択
- マイクOFF／ON（初期値は毎回OFF）
- 自動・720p・1080p
- 自動・30fps・60fps
- 軽量・標準・高画質
- 5分・10分・20分の録画上限
- 実FPSを考慮したビットレート設定
- 録画時間、推定容量、音声状態の表示
- 録画チャンクをIndexedDBへ順次退避
- 中断された録画の次回起動時復元
- 保存容量に応じた自動停止

### 操作画面

- スマートフォンでは設定を下部シートに表示
- PCでは設定パネルを常時表示
- 420px未満の画面でも、写真形式、マイク、画質、ピント、露出などを操作可能
- 写真・動画の全画面撮影モード
- スマートフォンでは下部シート、PCでは2カラムの履歴ビューア

### 履歴と復元

- 写真と動画をIndexedDBへ端末内保存
- 次回起動時の履歴復元
- 複数選択、選択削除、複数ページPDF作成

### PWA

- インストール可能
- オフラインでアプリ画面を起動
- 新しいService Workerの更新通知
- 独立したプライバシーポリシー

## ピント操作について

Webブラウザで利用できるピント機能は、端末、カメラ、ブラウザごとに異なります。

- `pointsOfInterest`と`single-shot`の両方がカメラ能力として公開される場合だけ、タップ位置AFを要求します。
- `single-shot`だけが利用可能な場合は、タップ位置ではなく画面中央のAFを実行します。
- `focusDistance`と`manual`が利用可能な場合は、手動ピントスライダーを表示します。
- いずれも公開されない場合は、端末側の自動フォーカスへ任せます。

未対応の`pointsOfInterest`を送ると、AFではなく自動露出の測光点だけが変化する端末があるため、能力が明示されないカメラには送信しません。

位置指定AFをWeb APIが公開しない端末では、「端末カメラ」を選ぶことでOS標準の撮影画面を開けます。標準カメラ内のタップフォーカスを使用した後、撮影結果をQuiet Cameraの履歴へ取り込みます。ただし、標準カメラの画面やシャッター処理をQuiet Camera側から制御することはできません。

## プライバシー設計

- 写真・映像・音声を自動アップロードしない
- 端末標準カメラで撮影したファイルも、利用者が選択した後にブラウザ内へ読み込むだけで自動送信しない
- マイク権限は動画設定をONにした場合だけ要求
- マイク設定は再起動時に必ずOFFへ戻す
- 位置情報を取得しない
- アクセス解析、広告SDK、ログイン、クラウド保存を使用しない
- 撮影結果と録画一時データはIndexedDBへ保存し、履歴から削除可能

## ローカルで確認

カメラ機能はHTTPSまたは`localhost`で動作します。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000`を開きます。

2. **Deploy from a branch** を選ぶ
3. `main`ブランチの`/ (root)`を指定して保存する
4. Android Chrome、iPhone Safari、PCで実機検証する

## 既知の制約

- 位置指定AF、手動ピント、ズーム、露出、ライト、60fps、1080pはカメラとブラウザの対応状況に依存します。
- PWAから位置指定AFが公開されない端末では、Quiet Camera独自画面のままネイティブカメラと同じタップAFは実現できません。
- 端末標準カメラの起動方法、前面／背面指定、撮影後に返るファイル形式はOSとブラウザに依存します。
- iPhone Safariでは標準カメラまたは写真選択のどちらを表示するかがOS設定やバージョンに左右される場合があります。
- ブラウザがHEIC／HEIFをデコードできない場合、その画像はQuiet Cameraの履歴へ取り込めません。
- 仮想カメラやUSBキャプチャーでは、ピント、露出、ライトなどが提供されない場合があります。
- 録画中のチャンクはIndexedDBへ退避しますが、録画終了時のファイル結合には一時的なメモリが必要です。
- 標準カメラアプリ固有のHDR、夜景合成、手ぶれ補正をQuiet Camera独自画面内で完全には再現できません。
- iPhoneでは共有シートから「画像を保存」または「ファイルに保存」を選ぶ方法が確実です。
- サイトデータを消去するとアプリ内履歴も削除されます。

## 利用上の注意

人物や私有地を撮影・録画するときは、相手の同意と撮影場所の規則を守ってください。無断撮影、盗撮、撮影禁止場所での使用など、違法・迷惑な撮影や録画には使用しないでください。
