# Quiet Camera

写真と動画をブラウザ内で処理する、プライバシー重視のカメラPWAです。撮影データは自動送信されず、広告・解析・アカウント機能もありません。アプリ自身は撮影音を再生しませんが、OS・ブラウザ・端末を無音にする機能ではありません。

## 主な機能

### カメラ制御

- 前面／背面カメラ切替
- 内蔵カメラ、USBカメラ、仮想カメラを含むカメラ選択
- 選択した`deviceId`の保存と、切断時の自動フォールバック
- カメラの接続・切断を`devicechange`で検出
- ズームとライトは対応時だけ表示し、露出補正と手動ピントは非対応理由を設定内に明示
- 露出補正は端末の最小値を基準にした整数インデックスで管理し、0EVに最も近い対応値へ戻せる
- 手動ピントは端末の有効範囲と刻み幅へ丸めて適用
- 設定適用後に`getSettings()`を読み直し、無視された設定を成功扱いしない
- 位置指定AFに対応すると明示されたカメラだけタップ位置を送信
- 位置指定AFがない場合は、単発中央AFまたは手動ピントへ切り替え

### 写真

- 0秒・3秒・10秒セルフタイマー
- 4:3・1:1・16:9の表示比率切替
- JPEG・PNG・WebP・PDF出力
- 複数写真をまとめた複数ページPDF
- 対応環境では`ImageCapture.takePhoto()`の高解像度画像を使用
- センサー画像とプレビューの比率が異なる場合も、高解像度画像を画面表示の比率へ中央クロップ
- スマホの縦長プレビューを含め、画面で見えている比率に合わせて保存
- 自撮りの鏡像保存切替
- 撮影後確認の「毎回・2秒・なし」

### 動画

- MP4またはWebMの自動選択
- マイクOFF／ON（初期値は毎回OFF）
- 動画モードでは設定を開かなくても「現在 MIC OFF／ON」を常時表示し、表示からマイク設定へ直接移動
- 自動・720p・1080p
- 自動・30fps・60fps
- 軽量・標準・高画質
- 5分・10分・20分の録画上限
- 実FPSを考慮したビットレート設定
- 録画時間、推定容量、音声状態の表示
- 録画チャンクをIndexedDBへ順次退避
- 中断された録画を次回起動時に再生検証し、可能な場合だけ復元
- 復元できない一時データの明示、手動再試行、削除
- 保存容量に応じた自動停止

### 操作画面

- スマートフォンでは設定を下部シートに表示
- 十分な高さがあるPCでは設定パネルを表示し、短い画面・横向き・全画面では下部シートへ切替
- 420px未満の画面でも、写真形式、マイク、画質、ピント、露出などを操作可能
- 写真・動画の全画面撮影モード
- スマートフォンでは下部シート、PCでは2カラムの履歴ビューア

### 履歴と復元

- 写真と動画をIndexedDBへ端末内保存
- 次回起動時の履歴復元
- 実サムネイルを使った60件単位のページ読み込み
- 複数選択、選択削除、最大20枚の複数ページPDF作成

### PWA

- インストール可能
- 192px・512px・Apple touch iconを含むインストール用アイコン
- オフラインでアプリ画面を起動
- 新しいService Workerの更新通知
- 独立したプライバシーポリシー

## ピント操作について

Webブラウザで利用できるピント機能は、端末、カメラ、ブラウザごとに異なります。

- ブラウザが`pointsOfInterest`を対応制約として公開し、カメラが`single-shot`または`continuous`を公開する場合だけ、タップ位置AFを要求します。
- `single-shot`だけが利用可能な場合は、タップ位置ではなく画面中央のAFを実行します。
- `focusDistance`と`manual`が利用可能な場合は、手動ピントスライダーを表示します。
- いずれも公開されない場合は、端末側の自動フォーカスへ任せます。

`applyConstraints()`が解決しても物理的な合焦成功までは確認できないため、UIは「AF要求」として扱い、合焦済みとは表示しません。

## プライバシー設計

- 写真・映像・音声を自動アップロードしない
- マイク権限は動画設定をONにした場合だけ要求
- マイク設定は再起動時に必ずOFFへ戻す
- 位置情報を取得しない
- アクセス解析、広告SDK、ログイン、クラウド保存を使用しない
- 撮影結果と録画一時データはIndexedDBへ保存し、履歴から削除可能
- カメラ選択と撮影設定はlocalStorageへ保存し、マイク設定は毎回OFFへ戻す
- ユーザーが共有・保存を選んだ後は、選択したアプリや保存先の規約に従う

## 既知の制約

- 位置指定AF、手動ピント、ズーム、露出、ライト、60fps、1080pはカメラとブラウザの対応状況に依存します。
- PWAから位置指定AFが公開されない端末では、ネイティブカメラアプリと同じタップAFは実現できません。
- 仮想カメラやUSBキャプチャーでは、ピント、露出、ライトなどが提供されない場合があります。
- 録画中のチャンクはIndexedDBへ退避しますが、録画終了時のファイル結合には一時的なメモリが必要です。
- 空き容量のうち、録画チャンクと完成ファイルが一時的に共存できる範囲だけを録画上限に使用します。
- 中断録画の復元はブラウザが再生可能なデータだけが対象です。復元できない一時データは履歴画面で再試行または削除できます。
- 複数ページPDFはメモリ負荷を抑えるため一度に20枚までで、各ページを最大2048pxへ縮小します。
- 標準カメラアプリ固有のHDR、夜景合成、手ぶれ補正を完全には再現できません。
- iPhoneでは共有シートから「画像を保存」または「ファイルに保存」を選ぶ方法が確実です。
- サイトデータを消去するとアプリ内履歴も削除されます。
- ブラウザが永続保存を許可しない場合、容量整理によって履歴が削除されることがあります。
- Quiet Cameraは効果音を再生しませんが、端末・OS・ブラウザによる音を制御せず、無音を保証しません。

## 実機確認

2026-08-15時点で、Galaxy S25（Android Chrome）とiPad mini 7（Safari）を使い、写真、音声OFF／ON動画、再生、前後カメラ、縦横3比率、ライト、履歴、設定シートを確認しています。Pixel 8aでは写真、ライト、ズーム、露出、画面比率を確認しました。

- Galaxy S25: 10秒MP4の保存・再生、録画取消、前面鏡像・背面復帰、縦横4:3／1:1／16:9を確認
- iPad mini 7: 音声OFF／ON動画の保存・再生、前後切替、縦横3比率、設定シート、非対応露出の説明を確認
- Pixel 8a: 高解像度4:3写真、履歴、ライト、ズーム、露出を確認

端末標準の連続AFとWeb APIから要求したAFの物理的な合焦結果は区別できないため、実際の合焦成功は保証しません。長時間録画、容量逼迫、強制終了復旧、オフライン起動、支援技術は追加確認項目です。

## 利用上の注意

人物や私有地を撮影・録画するときは、相手の同意と撮影場所の規則を守ってください。無断撮影、盗撮、撮影禁止場所での使用など、違法・迷惑な撮影や録画には使用しないでください。
