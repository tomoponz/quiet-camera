# Quiet Camera

写真・動画・音声を端末内だけで処理する、プライバシー重視のカメラPWAです。撮影結果は自動送信されず、広告、解析、ログイン、クラウド保存を使用しません。

## 主な機能

### 写真

- JPEG・PNG・WebP・1ページPDF
- Image Capture APIによる高解像度静止画を優先し、非対応時はCanvasへフォールバック
- 4:3・1:1・16:9
- 3秒・10秒タイマー
- タップフォーカス、連続AFフォールバック
- object-fitによる切り抜きを考慮したフォーカス座標変換
- ズーム、ピンチズーム、露出補正、ライト（対応端末）
- 前面カメラの鏡像保存切替
- 撮影後プレビューの表示方法を選択

### 動画

- MP4／WebM自動選択
- マイクOFF／ON（起動時は必ずOFF）
- 720p／1080p、自動／30／60fps、品質選択
- 60fpsを考慮したビットレート計算
- 録画の一時停止・再開・破棄
- 設定可能な録画時間上限と512MBの安全上限
- 1秒単位の録画チャンクをIndexedDBへ保存し、録画中のRAM増加を抑制
- 中断された録画の次回起動時復元

### 履歴・保存

- 写真・動画をIndexedDBへ一時保存
- 再読み込み後も履歴を復元
- 複数選択・一括削除
- 選択した写真から複数ページPDFを作成
- 端末ストレージ使用量の表示
- スマートフォンとPCで異なるレビュー画面レイアウト

### PWA・品質管理

- オフライン起動
- アプリ更新通知
- 設定保存（マイクだけは毎回OFFへ戻す）
- GitHub Actionsで構文検査と単体テスト

## Galaxy S25などのタップフォーカス

ブラウザのカメラAPIが位置指定AFを公開している場合は、表示上のタップ座標を元映像のピクセル座標へ変換してAF・AE・AWBの注目点を設定します。

位置指定AFが公開されない端末／ブラウザでは、連続AFまたは単発AFの再適用を試し、最終的には端末本来の自動AFへフォールバックします。WebアプリからSamsung純正カメラと同等のAF制御を強制することはできません。

## 既知の制約

- カメラ機能、MP4、ズーム、露出、ライト、位置指定AF、60fpsは端末とブラウザに依存します。
- IndexedDBへチャンクを退避しても、録画終了後のプレビュー・共有時には動画全体のBlobを生成するため、非常に大きな動画はメモリを消費します。
- iOSではブラウザがバックグラウンドへ移動すると録画が中断される場合があります。
- 複数ページPDFは画像をA4へ配置する機能で、OCR・台形補正・自動輪郭検出は未実装です。
- 無音動作はOSと端末の仕様に依存し、保証できません。
