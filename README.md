# Quiet Camera

ブラウザだけで動作する、シンプルなカメラPWAです。撮影画像は端末内で生成され、アプリのサーバーへ送信されません。

## 主な機能

- 前面／背面カメラ切替
- 0秒・3秒・10秒セルフタイマー
- 4:3・1:1・16:9の比率切替
- 3分割グリッド
- JPEG保存
- Web Share APIによる共有
- PWAインストール
- オフラインでのアプリ画面起動

## プライバシー設計

- カメラ映像と写真はブラウザ内だけで処理
- 音声を取得しない
- 位置情報を取得しない
- アクセス解析や広告SDKを使用しない
- 撮影画像を自動アップロードしない

## ローカルで確認

カメラ機能はHTTPSまたは`localhost`で動作します。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000`を開きます。

## GitHub Pagesで公開

1. TSUKUTTAで一般公開する場合は、リポジトリの公開範囲を確認する
2. GitHubの **Settings → Pages** を開く
3. **Deploy from a branch** を選ぶ
4. `main`ブランチの`/ (root)`を指定して保存する
5. 公開されたURLをスマートフォンで検証する
6. 問題がなければ公開URLをTSUKUTTAへ登録する

公開URLの例:

```text
https://tomoponz.github.io/quiet-camera/
```

## 既知の制約

- ブラウザの映像フレームをJPEG化する方式のため、標準カメラアプリと画質や補正が異なる場合があります。
- レンズ選択、手ぶれ補正、ナイトモードなどは端末とブラウザに依存します。
- 端末やOSの仕様により、無音動作を保証できない場合があります。
- iPhoneでは「共有」から「画像を保存」を選ぶ方法が確実です。
- SVGアイコンに対応しない古い環境では、ホーム画面アイコンが簡略表示される場合があります。

## 利用上の注意

人物や私有地を撮影するときは、相手の同意と撮影場所の規則を守ってください。無断撮影、盗撮、撮影禁止場所での使用など、違法・迷惑な撮影には使用しないでください。
