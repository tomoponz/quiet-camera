# 開発とAIの利用

[READMEへ戻る](../README.md)

Quiet Cameraの開発では、コードの実装や確認にAIを活用しています。この文書では、文書整理時の公開main `9922270` に基づき、2026年10月31日時点で確認できる開発経緯を記します。使用したAI・ツールと、根拠が確認できる範囲を分けて記載しています。なお、開発にAIを利用したことは、アプリの利用中に撮影データをAIへ送信することを意味しません。

## 人が行う判断と検証

公開記事では、何を作るかという機能選択や実際の使いやすさを作者が判断し、AIによる実装と実機での確認を繰り返した経緯が説明されています。ただし、この経緯だけで現在版のすべての操作が実機で確認済みとは扱いません。版ごとの確認範囲と未確認事項は[検証記録](verification.md)を参照してください。

コードの構造を学ぶ入口は[構成と処理の流れ](architecture.md)にまとめています。画面の部品、ブラウザーAPIとの分担、撮影から保存までの処理を順番にたどることができます。
