## 起動する

1. [Quiet Camera](https://tomoponz.github.io/quiet-camera/)を開きます。
2. 「カメラを許可」を押し、ブラウザーのカメラ利用を許可します。
3. カメラ映像が表示されてから、写真または動画を選びます。

写真モードでカメラの権限を拒否すると撮影できません。「カメラを利用できません」の案内から設定方法を確認し、ブラウザーやOSの権限を変更した後に「もう一度試す」を押してください。動画モードでマイクも要求した場合の拒否は、下記「動画を撮る」の手順を参照してください。カメラが見つからない場合や、ほかのアプリが使用中で開けない場合もメッセージが表示されます。カメラの利用にはHTTPSなどの安全な接続環境が必要です。

初回は写真モード、写真形式はJPEGで、マイクは使用しません。初めて動画へ切り替えたときにマイクを準備します。手動でOFFにした設定は次回起動後も維持します。前回の動画モードが復元された場合も、ページを開くだけではカメラやマイクを取得せず、「カメラを許可」を押してから準備します。権限とデータの扱いは[データと権限](data-and-permissions.md)を参照してください。

実装の根拠：[起動画面とボタン](../index.html)、[カメラの起動と失敗時の処理](../assets/js/camera-devices.js)、[設定の読み込み](../assets/js/core.js)。

## 写真を撮る

1. 「写真」を選び、画面に写る範囲を確認します。
2. 必要に応じて比率、タイマー、ズームなどを変更します。
3. シャッターボタンを押します。「写真を保存しました」と表示されると、アプリの履歴に記録されます。
4. 「履歴」で写真を確認し、必要な写真を「端末に保存」または「共有」で取り出します。

写真は表示枠の比率に合わせ、元画像の中央を切り出して保存します。プレビューの1フレームから保存する場合は、その映像を表示枠の比率に切り出します。高解像度の静止画は、端末によってプレビューと画角が異なることがあるため、保存後の画像も確認してください。端末とブラウザーが対応している場合は `ImageCapture` で静止画を取得し、利用できない場合や失敗した場合はプレビュー映像の1フレームを使います。カメラの最大解像度で保存できるとは限りません。

設定ではJPEG・PNG・WebP・PDFを選べます。写真品質の初期値は「高画質」で、実際の画像形式や圧縮結果はブラウザーの対応状況に依存します。自撮り写真は初期状態で鏡像のまま保存され、「自撮り保存」の設定で変更できます。撮影後に確認画面は自動では開きません。

実装の根拠：[写真の取得・切り出し・履歴保存](../assets/js/photo.js)、[写真設定](../index.html)。

## 動画を撮る

1. 「動画」を選びます。手動OFFなどの場合を除き、マイクの利用を要求します。ブラウザーの確認が表示されたら、音声を入れる場合は許可します。カメラをまだ起動していない場合は、カメラとマイクをまとめて要求します。
2. 映像と操作ボタンが戻るまで待ち、MIC表示を確認します。音声が不要なら設定の「マイク」をOFFにしてください。この選択は写真との切り替え後や次回起動後も維持します。画面のMIC表示からも設定を開けます。
3. 録画ボタンで開始し、もう一度押すと停止します。
4. 「保存中」の処理が終わった後に「履歴」で確認します。

動画サイズは自動・720p・1080p、FPSは自動・30・60から選択できます。これらはブラウザーへ要求する設定値であり、実際の出力は対応状況によって変わります。ファイル形式は対応状況に応じてMP4・WebMから優先して選び、指定できない場合はブラウザーの既定形式を使います。録画時間の上限は5・10・20分から選べ、初期値は10分です。保存容量などの条件により、上限時間より早く停止することがあります。

マイクの許可を拒否すると、MIC OFF・「音声なし」を表示し、アプリ独自の確認ダイアログは出しません。直前までカメラ映像が取得できていた場合は、音声なしで接続し直します。カメラも未起動だった場合は続けて再要求せず、「カメラを許可」を押すまで待ちます。同じ画面を開いている間は、写真と動画を往復してもマイクを再要求しません。音声を使いたくなった場合は、必要に応じてブラウザー・OSの権限を変更し、設定の「マイク」をONにして再試行してください。

録画中の「録画取消」は、進行中の録画を破棄する操作です。「現在の録画を破棄しますか？」の確認に同意し、破棄が完了すると、その録画は履歴に追加されません。カウントダウン中・録画中・保存処理中は、カメラ切替や設定変更などの操作が制限されます。マイクONでも有効な音声トラックを取得できていない場合は、説明を表示して録画開始を止めます。

保存が完了しなかった録画がある場合は、履歴に復元や一時データの操作が表示されることがあります。必ず復元できるとは限らないため、内容と注意点を[データと権限](data-and-permissions.md)で確認してください。

実装の根拠：[マイクを含む取得要求](../assets/js/camera-devices.js)、[形式選択](../assets/js/video.js)、[録画と保存処理](../assets/js/video.js)。

## 撮影画面を調整する

| 操作 | 使い方と条件 |
| --- | --- |
| カメラ切替 | 切替ボタンで前面・背面を切り替えます。複数のカメラが検出された場合は設定からカメラを選べます。 |
| タイマー | ボタンでOFF・3秒・10秒を切り替えます。写真撮影と動画の録画開始に使えます。 |
| ズーム | 対応カメラではスライダーが表示されます。倍率の範囲はカメラによって異なります。 |
| ライト | 対応カメラのライトを切り替えます。非対応時や録画中などは操作できません。 |
| ピント | 映像をタップすると、対応状況に応じて位置指定や中央・連続オートフォーカスを要求します。枠の表示は物理的にピントが合ったことを保証するものではありません。手動調整に対応する場合は設定にも表示されます。 |
| 明るさ | 露出補正に対応するカメラでは設定から調整できます。 |
| グリッド | 構図の目安となる補助線の表示を切り替えます。 |
| 縦・横の表示 | 端末の向きや画面サイズに合わせて配置が変わります。写真は保存範囲、動画はカメラの取得映像全体を表示する設計です。 |
| 全画面 | 全画面ボタンで表示領域を広げます。ブラウザーが全画面APIに対応しない場合など、アドレスバーまで隠れるとは限りません。 |

実装の根拠：[カメラの選択と切替](../assets/js/camera-devices.js)、[カメラ操作](../assets/js/camera-controls.js)、[縦横の配置](../assets/js/camera-overlay.js)、[全画面](../assets/js/fullscreen.js)。

## 履歴から確認・取り出し・削除をする

履歴ボタン（「履歴」または直近の撮影サムネイル）を押すと、「撮影履歴」が開きます。項目を選ぶと、撮影した写真や動画を確認できます。詳細画面の「← 新しい項目」「古い項目 →」ボタンで前後へ移動でき、タッチ操作では左スワイプで古い項目、右スワイプで新しい項目へ進みます。動画は再生操作を行って確認します。撮影後に写真から作成したPDF文書は、この前後移動の対象外です。

| 操作 | 結果 |
| --- | --- |
| 端末に保存 | ブラウザーのダウンロードを開始します。保存先や写真アプリへの取り込み方法はブラウザー・OSによって異なります。 |
| 共有 | 対応環境ではOSの共有画面を開きます。1件の共有が非対応の場合はダウンロードに切り替わります。共有先は利用者自身が選びます。 |
| 表示中の写真をPDFにする | 表示中の画像からPDFを作成し、別の項目として履歴に追加します。元の写真は残ります。 |
| 削除 | 確認後にアプリの履歴データを削除します。すでに取り出したファイルや共有先のコピーは消えません。ごみ箱や取り消し機能はありません。 |

履歴の「選択」ボタンまたは項目の長押しで、複数の項目を選べます。複数件の「端末に保存」では、元ファイルをZIPにまとめてダウンロードします。複数件の共有に対応しない環境では保存を利用してください。画像の写真を最大20枚まで選んで複数ページPDFにまとめることもできます。動画や既存のPDFは結合の対象にできません。

保存済み動画の断片が欠けているなどの理由で読み出せない履歴項目は「読み込めない項目」と表示します。元データを自動では削除せず、正常な項目は引き続き開けます。読み込めない項目を含む選択では保存・共有・PDF作成を行えません。削除する場合は、選択して確認に同意する必要があります。詳細画面で前後の項目を読み込めない場合は、履歴へ戻って別の項目を開いてください。

撮影の保存が完了した後で履歴表示の更新だけに失敗した場合は、保存済みであることと再表示の案内を通知します。起動時は既存の履歴を先に表示し、中断録画の復元が終わった後に更新します。

履歴はブラウザー内の保存領域であり、端末の写真フォルダーへの保存とは異なります。残しておきたい撮影データは、履歴からファイルとして取り出し、保存先で実際に開けることを確認してください。

実装の根拠：[前後移動](../assets/js/photo-review.js)、[保存・共有・PDF・削除](../assets/js/ui.js)、[複数選択の操作](../assets/js/gallery-selection.js)。
