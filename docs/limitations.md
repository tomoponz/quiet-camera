# 制約と対応環境

[READMEへ戻る](../README.md)

現在のファイル配置は[構成と処理の流れ](architecture.md)を参照してください。ソースへのリンクは、この文書と同じ版の実装を指します。

この文書は `v2026.10.31.3` の制約を説明しています。機能がコード上に存在することと、特定の端末で動作確認を終えていることは別です。端末ごとの確認日・対象版・未確認事項は[検証記録](verification.md)を参照してください。

## 動作に必要な条件

| 機能 | 主な条件・依存先 |
| --- | --- |
| カメラを起動する | HTTPSなどの安全なコンテキスト、`getUserMedia()`、カメラ権限、利用可能なカメラが必要です。 |
| 写真を撮る | 取得した映像とCanvasを使います。高解像度の静止画取得は`ImageCapture`の対応状況に依存し、利用できない場合はプレビュー映像の1フレームを使います。 |
| 動画を録る | `MediaRecorder`、IndexedDB、タブ間の処理を調整するWeb Locksが必要です。録画形式や実際の解像度・fpsはブラウザーとカメラに依存します。 |
| 履歴を保持する | IndexedDBの利用と空き容量が必要です。サイトデータ消去やブラウザーの容量管理による消失を防ぐ保証はありません。 |
| ファイルを共有する | ファイル共有に対応したWeb Share APIが必要です。単独の閲覧画面では非対応時に保存へ切り替え、複数選択画面では「端末に保存」を案内します。 |
| インストール・オフライン起動 | PWAとService Workerへの対応、事前のファイル取得が必要です。オフライン起動はカメラ権限や保存容量を代替しません。 |

`MediaRecorder` が利用できない環境では動画モードを無効にします。Web Locksが使えない場合も安全な録画を開始できず、中断録画の復元や一時データの操作が制限されます。すべてのブラウザーや環境で同じように動作するわけではありません。

## カメラと画面表示

ライト、ズーム、露出補正、手動ピント、タップ位置へのAF要求、1080p、60fpsは、カメラとブラウザーが公開している機能の範囲で利用します。非対応の機能は非表示または無効表示となり、必要に応じて理由が案内されます。端末の内蔵カメラ機能や標準カメラアプリと同じ動作を保証するものではありません。

AF操作はブラウザーのAPIへ要求を送る処理です。要求が成功しても、被写体に物理的にピントが合ったことまでは証明できません。ライトやズームの効き方も含め、実際の端末で結果を確認してください。

写真は選択した比率の中央部分を切り出して保存します。動画は取得した映像ストリームの比率を使い、指定した比率で取得できない場合は実際の映像に近い比率へ表示を戻します。縦横の画面表示切替、写真の切り出し範囲、保存される動画ファイルの画素比率はそれぞれ別の処理であり、写真と動画の出力が常に同じ寸法になるわけではありません。

確認したコードには、Quiet Camera独自のシャッター効果音を再生する処理はありません。ただし、OS・ブラウザー・端末が鳴らす通知音や操作音を止める機能ではないため、すべての環境で無音になるとは保証できません。

## 録画時間・容量・中断

録画時間の上限設定は5分・10分・20分です。設定した時間に達する前でも、保存容量の見積もりや出力データ量、書き込み失敗によって早期に停止する場合があります。

現在の実装では、録画の通常停止目標を512 MiB、停止後の追加出力を見込んだ確定処理の上限を576 MiBとしています。容量見積もりには32 MiBの予備領域と64 MiBの追加出力枠を含みます。これらはアプリ側の停止目安・処理上限であり、その容量まで必ず録画・保存できるという保証ではありません。確定処理や再生確認には一時的なメモリも消費します。

録画中はデータを断片に分けてIndexedDBへ書き込みます。中断後は、永続化できたデータの読み込み確認を行い、確認できた場合に履歴へ復元します。OSによる強制終了、書き込み前のデータ消失、保存領域自体の消去から必ず復元できるわけではありません。

復元できなかった一時データは保持され、履歴から再試行や「一時データを保存」を選べます。この操作で書き出されたファイルは再生未確認の状態です。空であると判定できるデータは整理しますが、不明なデータを無条件に削除する処理ではありません。また、旧版のタブと新版を同時に開いていると録画管理の方式が競合する場合があるため、復元案内に従って旧版のタブを閉じてください。

## PDF・複数保存

PDF形式での1枚撮影・1枚のPDF書き出し・複数ページPDFのいずれも、埋め込む画像の長辺は最大2048pxです。PDF用画像への再圧縮には固定のJPEG品質0.92を使います。写真の品質設定でこの値は変わりませんが、元画像の画質の影響は残ります。複数ページPDFには画像の写真を最大20枚までまとめられます。動画や既存PDFの結合には対応していません。複数選択時の「端末に保存」は、元ファイルをZIPにまとめてダウンロードします。ZIPやPDFの生成時にも一時的なメモリと保存容量が必要です。

## 更新と確認範囲

公開サーバー上の最新ファイルと、利用者の端末に残るPWAのキャッシュが一時的に異なる場合があります。公開サイトのファイルをHTTPで確認しただけでは、すでに開いているタブやインストール済みPWAが同じ版で動いていることまでは証明できません。

合成映像を使ったPCブラウザーの自動試験は、実カメラ・実マイク・実機の保存先やOS共有先の動作確認とは区別しています。未確認のOSやブラウザーでの動作は保証していません。機能ごとの対応条件や実機での確認範囲は[検証記録](verification.md)を参照してください。
